# Home Assistant 用 Gree Plus

[English](README.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [Português (Brasil)](README.pt-BR.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md)

Gree Plus は、技術愛好家向けにコミュニティが保守する非公式の Home Assistant インテグレーションです。ユーザーの GREE+ クラウドアカウントを使用して、対応する GREE+ エアコンを Home Assistant に接続します。

## 機能

- 電源、運転モード、目標温度、ファン速度の制御。
- 摂氏、華氏、および機種ごとの温度刻み幅に対応。
- セットアップ時および制御コマンド実行後の状態更新。
- バックグラウンドで継続的にポーリングせず、手動更新に対応。

## 要件

- Home Assistant 2026.9.1 以降。
- 対応するエアコンが少なくとも 1 台登録された GREE+ アカウント。
- Home Assistant からクラウドサービスへ接続できるインターネット環境。

## インストール

1. Home Assistant で HACS を開きます。
2. このリポジトリを **Integration** カテゴリのカスタムリポジトリとして追加します。
3. **Gree Plus** をダウンロードし、Home Assistant を再起動します。
4. **設定 > デバイスとサービス > 統合を追加** を開き、**Gree Plus** を選択します。

## 設定

アカウントの地域を選択し、デバイスが登録されている GREE+ アカウントでサインインします。再接続に必要な認証セッション情報は Home Assistant に保存されます。

追加の認証が必要な場合は、Home Assistant に表示されるサインインリンクを開き、ブラウザーで認証を完了してから、アドレスバーの完全な `http://localhost/...` アドレスを貼り付けます。認証情報フォームを繰り返し送信しないでください。

## 状態更新

このインテグレーションは継続的なポーリングを行いません。セットアップ時、制御コマンド実行後、およびエンティティの手動更新時に状態を取得します。Home Assistant 以外で行われた変更は、次回の更新まで表示されない場合があります。

## 制限事項

- 対応する操作は、電源、モード、目標温度、ファン速度に限定されます。
- 利用できるモードと温度刻み幅は、デバイスの機能によって異なります。
- 動作はクラウドサービスの可用性と互換性に依存します。
