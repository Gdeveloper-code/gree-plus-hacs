# Home Assistant용 Gree Plus

[English](README.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [Português (Brasil)](README.pt-BR.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md)

Gree Plus는 기술 애호가를 위해 커뮤니티에서 관리하는 비공식 Home Assistant 통합입니다. 사용자의 GREE+ 클라우드 계정을 통해 지원되는 GREE+ 에어컨을 Home Assistant에 연결합니다.

## 기능

- 전원, HVAC 모드, 목표 온도 및 팬 속도 제어.
- 섭씨, 화씨 및 모델별 온도 조절 간격 지원.
- 설정 후와 제어 명령 실행 후 상태 새로 고침.
- 백그라운드 연속 폴링 없이 수동 새로 고침 지원.

## 요구 사항

- Home Assistant 2026.9.1 이상.
- 지원되는 에어컨이 하나 이상 연결된 GREE+ 계정.
- Home Assistant에서 클라우드 서비스로 연결할 수 있는 인터넷 접속.

## 설치

1. Home Assistant에서 HACS를 엽니다.
2. 이 저장소를 **Integration** 범주의 사용자 지정 저장소로 추가합니다.
3. **Gree Plus**를 다운로드하고 Home Assistant를 다시 시작합니다.
4. **설정 > 기기 및 서비스 > 통합 구성요소 추가**를 열고 **Gree Plus**를 선택합니다.

## 구성

계정 지역을 선택한 다음 기기가 연결된 GREE+ 계정으로 로그인합니다. 통합이 다시 연결할 수 있도록 Home Assistant가 인증 세션 데이터를 저장합니다.

추가 인증이 필요한 경우 Home Assistant에 표시된 로그인 링크를 열고 브라우저에서 인증을 완료한 다음 주소 표시줄의 전체 `http://localhost/...` 주소를 붙여 넣습니다. 자격 증명 양식을 반복해서 제출하지 마십시오.

## 새로 고침 동작

이 통합은 지속적으로 폴링하지 않습니다. 설정 시, 제어 명령 실행 후, 엔터티 수동 업데이트 요청 시 상태를 조회합니다. Home Assistant 외부에서 발생한 변경 사항은 다음 새로 고침 전까지 표시되지 않을 수 있습니다.

## 제한 사항

- 지원되는 제어는 전원, 모드, 목표 온도 및 팬 속도로 제한됩니다.
- 사용 가능한 모드와 온도 조절 간격은 기기 기능에 따라 달라집니다.
- 작동 여부는 클라우드 서비스의 가용성과 호환성에 따라 달라집니다.

## 지원 및 개인정보 보호

문제는 저장소의 Issue Tracker를 통해 보고하십시오. 진단 정보나 로그를 첨부하기 전에 계정 식별자, 인증 데이터, 기기 식별자, 이름 및 위치 정보를 제거하십시오.
