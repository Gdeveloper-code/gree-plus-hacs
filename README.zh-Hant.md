# Gree Plus for Home Assistant

[English](README.md) | [簡體中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md)

Gree Plus 是一個非官方、由社群維護的 Home Assistant 整合，面向技術愛好者。它透過使用者的 GREE+ 雲端帳戶，將受支援的 GREE+ 空調接入 Home Assistant。

## 功能

- 控制開關、運行模式、目標溫度和風速。
- 支援攝氏度、華氏度以及裝置提供的溫度步進。
- 在初始化和控制操作後更新裝置狀態。
- 支援手動更新，不進行背景持續輪詢。

## 使用要求

- Home Assistant 2026.9.1 或更高版本。
- 已綁定至少一台受支援空調的 GREE+ 帳戶。
- Home Assistant 可以存取對應的雲端服務。

## 安裝

1. 在 Home Assistant 中開啟 HACS。
2. 將本儲存庫新增為類別為 **Integration** 的自訂儲存庫。
3. 下載 **Gree Plus** 並重新啟動 Home Assistant。
4. 前往 **設定 > 裝置與服務 > 新增整合**，選擇 **Gree Plus**。

## 設定

選擇帳戶所在區域，然後使用已綁定裝置的 GREE+ 帳戶登入。Home Assistant 會保存用於重新連線的認證工作階段資料。

如需額外驗證，請開啟 Home Assistant 顯示的登入連結，在瀏覽器中完成驗證碼等驗證，然後貼上瀏覽器網址列中的完整 `http://localhost/...` 位址。請勿重複提交帳號密碼表單。

## 更新機制

本整合不會持續輪詢。它會在初始化、控制操作完成後，以及使用者手動要求更新實體時查詢狀態。在 Home Assistant 之外產生的狀態變化，需要等到下一次更新後才會顯示。

## 限制

- 僅支援開關、模式、目標溫度和風速等基礎控制。
- 可用模式和溫度步進取決於具體裝置能力。
- 整合運作依賴雲端服務的可用性和相容性。
